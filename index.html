🖨️ Cetak Langsung Tanpa Dialog (POS80)

Browser tidak bisa langsung cetak tanpa menampilkan dialog print, ini pengaman dari browser itu sendiri. Solusi yang paling praktis untuk kasir/tablet: jalankan Google Chrome dengan mode kiosk-printing, maka tombol "Cetak Struk" akan langsung mencetak ke printer default tanpa dialog sama sekali.

chrome.exe --kiosk-printing --app="file:///lokasi/kasir.html"

Pastikan printer POS80 sudah disetel sebagai printer default di Windows/perangkat kasir kamu.

💾 Backup Data

Semua data (produk, transaksi, pengaturan) tersimpan lokal di browser ini saja (localStorage), bukan di folder file. Export backup secara berkala supaya data aman jika cache browser terhapus atau ganti perangkat.

🖨️ Printer Thermal Bluetooth

Cetak struk langsung ke printer thermal Bluetooth (ESC/POS) tanpa dialog browser. Mendukung RPP02N, dan printer BLE ESC/POS lainnya. Ukuran kertas 58mm/80mm mengikuti pengaturan di tab "Kertas & Cetak".

Belum terhubung ke printer
📌 Cara menggunakan:
1) Nyalakan printer dan aktifkan Bluetooth di perangkat.
2) Klik "Hubungkan Printer" → pilih nama printer dari daftar.
3) Setelah terhubung, tombol "Cetak Bluetooth" muncul di preview struk.
4) Printer otomatis memotong kertas setelah cetak (auto-cutter).
⚠️ Catatan Browser: Web Bluetooth memerlukan Chrome/Edge versi terbaru. Pada Android, buka via file:// mungkin perlu aktifkan flag di chrome://flags/#unsafely-treat-insecure-origin-as-secure lalu tambahkan URL file HTML-nya. Atau akses lewat localhost untuk hasil terbaik.

📷 Scan Barcode

Mengaktifkan kamera...
📌 Tips supaya barcode terbaca:
• Pastikan garis-garis barcode mengisi sebagian besar lebar kotak putih, jangan terlalu jauh/kecil.
• Jaga jarak sekitar 10–15cm, cahaya cukup terang, hindari pantulan/silau di kemasan.
• Tahan kamera tetap diam sejenak (jangan bergerak) sampai barcode terbaca.
• Bisa langsung scan produk berikutnya tanpa menutup jendela ini — klik "Selesai Scan" kalau sudah selesai semua.
💡 Fitur ini butuh izin kamera browser. Kamera paling stabil diakses lewat HTTPS (misalnya setelah diupload ke Netlify/Vercel) atau localhost (misalnya lewat ekstensi Live Server di VSCode). Membuka langsung dari file HTML (file://) kadang tetap bisa jalan di Chrome desktop, tapi tidak selalu konsisten di semua perangkat/browser.
